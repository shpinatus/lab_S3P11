# S3P11 Структуры — вариант 14 «Тарификация»

Исполнитель: Нестеренко М. (ИКТГ-2521)

Программа хранит тарифы операторов связи в динамическом массиве структур `Tariff`,
читает их из текстового файла (`data.txt`) и работает через меню:

1. Просмотр данных (таблица)
2. Корректировка записи по id
3. Добавление записи
4. Удаление записи
5. Вычисления: средняя абонентская плата, самый дешёвый и самый дорогой тариф,
   самый выгодный по цене 1 ГБ, подбор тарифов по бюджету
0. Выход с сохранением данных в новый файл (имя вводится с клавиатуры)

Структура записи: `id (int)`, `name`, `provider`, `type` (`string`),
`price (double)`, `minutes (int)`, `traffic (double)`.

Формат строки файла: `id;название;оператор;вид услуги;плата;минуты;трафик`

Сборка и запуск:

```
g++ main.cpp -o lab
./lab
```
